# 윤덕훈 캡슐 36통 one-off 분할 발송

## 이름 주의

- 스마트스토어 export와 Todoist의 정확한 수취인명은 `윤덕훈`.
- 대화 중 나온 `윤석훈`은 주문 구성 36통이 윤덕훈 주문과 정확히 일치하여 오타로 처리했다.

## 분할 사유

- 스타벅스 버츄오 호환 캡슐 총 36통을 한 번에 보내면 관부가세 문제가 생길 가능성이 있어 18통씩 두 번 발송한다.
- 구매는 일정과 무관하게 **36통 전량 진행**한다.
- 고객과 **2026-07-31(금) 18통 + 2026-08-04(화) 18통**으로 나누어 발송하기로 확정했다.
- 다른 수취인으로 나누어 한 번에 발송하는 대안은 더 이상 답변 대기 상태가 아니다.

## 🚨 배송비·최종 정산 시점

- 윤덕훈 주문은 금요일에 절반만 출고하므로 **2026-07-31에는 최종 정산하지 않는다.**
- 나머지 18통을 2026-08-04(화)에 출고한 뒤, 두 차례 발송분을 합쳐 최종 정산한다.
- 금요일과 화요일 모두 동일하게 18통씩 발송하므로 **화요일 윤덕훈 실배송비는 금요일 18통 실배송비와 사실상 같은 금액으로 예상**한다.
- 화요일 실제 한미 배송비가 확정되기 전에는 금요일 18통 배송비와 같은 금액을 추정치로 사용하되, 최종 정산은 실제 출고·배송비 확인 후 확정한다.

## 절대 규칙

1. `사야할 제품들` 구매 목록은 분할하지 않는다. 사용자가 36통 전량 구매한다고 명시했다.
2. 수취인별 포장/발송 목록만 금요일 18 + 화요일 18로 나눈다.
3. due date는 각 날짜의 최상위 `수취인별 주문` 부모에만 둔다.
4. `윤덕훈`과 상품 하위 task에는 due date/deadline을 넣지 않는다.
5. 상품명과 용량·수량을 축약하지 않는다.
6. 별도 변경 요청이 오기 전에는 다른 수취인을 만들거나 화요일 발송을 취소하지 않는다.
7. 금요일분만 보고 윤덕훈 주문의 최종 이익을 확정하지 않는다. 8/4 출고 후 두 발송분의 배송비를 함께 반영한다.
