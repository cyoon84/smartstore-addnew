**세금은 공통비가 아니다.** §19-3 의 "오버헤드를 품목가 비율로 안분" 은 **배달비·서비스수수료처럼
품목을 가리지 않는 비용**에만 쓴다. 품목마다 세율이 다르므로([[reference_hst_zero_rated]]),
과세품과 영세율품이 한 영수증에 섞이면 **세금 전액을 과세품에 붙인다.**

```
❌ 도착원가 = 품목가 + (세금 + 배달비 + 수수료) × 품목가비율
✅ 도착원가 = 품목가 + (그 품목의 세금) + 공통비 × 품목가비율
```

**판별:** LEARNED §3 세율표 — 일반 13% / **소스·원두커피·쿠키 0%** / 키즈의류·신발 5%.
표로 안 갈리면 사장님께 확인.

**Why — 손익 판정이 반대로 뒤집힌다.**
2026-11-03 Uber Eats 코스트코 비즈니스 센터: 품목 소계 $49.49(메이나드 퍼지피치 캔디 $18.56 +
라바짜 오로 **원두** $30.93) · 세금 $3.43 · 배달 $2.49 · 서비스 $3.46 · 예약배송 할인 −$2.50 ·
합 $56.37. 간접비 $6.88 을 통째로 비율 안분했다가 사장님: ***"젤리쪽이겠지"*** — 원두는
기본식품이라 세금 0%.

| | 비율 안분(❌) | 세금=젤리(✅) |
|---|---:|---:|
| 메이나드 도착원가 | $21.14 (₩20,316) | **$23.28 (₩22,376)** |
| 라바짜 도착원가 | $35.23 (₩33,857) | **$33.09 (₩31,796)** |
| 임지혜 순이익 | ₩8,244 | ₩6,184 |
| 김순임 순이익 | ₩5,269 | **₩7,330** |

비율 안분으로는 라바짜가 얇아 보여 "판매가를 올려야 한다"고 보고했는데, 바로잡으니
**라바짜가 더 남는다.** 안분 하나로 "어느 SKU 가 효자인가"(§7-2)가 반대로 나온다.

**How to apply:** 영수증을 COGS 로 쪼갤 때 ① 품목별 세율을 §3 표로 먼저 가른다
② 세금은 과세품에만 ③ 배달비·서비스수수료·봉투값만 품목가 비율로 안분
④ 품목 전용 프로모·리베이트는 그 품목에서 직접 차감(§19-3, [[feedback_nespresso_rebate_single_coffee]]).

⚠️ 세금 합이 `과세품 × 세율` 과 정확히 안 맞아도(이 건은 $0.24 초과) **근거 없는 잔차를 억지로
모델링하지 말 것**(§9). "영세율품 쪽이 아니다" 만 확정하면 충분하다.
