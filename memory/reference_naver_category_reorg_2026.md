네이버쇼핑 카테고리 트리는 고정이 아니라 분기 단위로 세분화/통합/신설이 일어난다(서드파티 셀러 커뮤니티 다수 확인, 공식 공지 원문은 접근 차단이라 미확보 — 신뢰도 중).

**2026-04-20~24 개편:** 식품 `과자/베이커리` 산하를 `젤리/사탕/초콜릿`·`스낵/과자`·`전통과자`로 분리. 화장품 `메이크업 픽서`·`패치` 신설. 생활/건강 `일회용품`(일회용젓가락·빨대 등) 주방잡화에서 분리독립. → 우리 [[feedback_naver_category_snack]]·§10 태그사전이 이미 이 분리 구조를 전제로 하고 있어 갭 없음(재확인만).

**2026-07-06~15 개편:** 여성신발 힐/펌프스/샌들 → 플랫폼·가보시힐 / 플랫폼·샌들로 통합. 가스레인지·인덕션·하이라이트 → 쿡탑 산하로 재그룹핑. 이어폰·블루투스이어폰 재그룹핑. `텀블러액세서리`·`이너백` 신설. (출처: ocschool.me, "카탈로그 필터 재점검" 실무글 — 광고 카탈로그 필터 관점, 신뢰도 중) → 우리 취급 카테고리(신발=운동화 계열, 텀블러=본品 자체)와 직접 안 겹침, 갭 없음.

**2026-07-22~26 개편:** `완구/매트`→`매트안전용품` 분리 + `완구/인형` 세분화, `세탁기+건조기세트`·`식물재배기` 신설, 저판매 품목군 통합(`CC크림`·`샤워코롱` 등). 개편 중 자동이관으로 의도와 다른 카테고리에 배정될 수 있음.

**Why:** §16 완구/레고/키덜트(`출산/육아>완구/인형>블록>레고` 50004258, 레고 43015 리오넬 메시 리스팅)가 이번 `완구/인형` 세분화 트리에 걸린다. 코드가 바뀌었는지·자동이관 후에도 맞는지는 원격에서 확인 불가(1차 소스 차단, guide xls 최신본 필요).

**🚨 2026-08-31 확인 — 로컬 guide xls 자체가 두 번의 7월 개편보다 오래됐다:** `guide/일괄등록 guide/category_20260606_023944.xls` 파일명 타임스탬프가 **2026-06-06**. 즉 이 xls는 07-06~15 개편도, 07-22~26 개편(완구/인형 세분화 포함)도 **반영 못 한 구버전**이다 — §15 원칙("코드는 guide 리스트가 유일한 진실")을 지키려 해도 지금 로컬 파일로는 레고 카테고리 코드가 여전히 유효한지 확인 자체가 불가능하다. i-boss 원문(7/22~26 개편 상세, `ab-6141-64514`)은 로그인월이라 insane-search 로도 접근 실패(Cloudflare 챌린지+로그인폼, terminal).

**How to apply:** 완구/유아 카테고리 신규 등록·리프레시 시 항상 `guide/일괄등록 guide/category_*.xls` **최신본**으로 재확인(§15 원칙). **액션 아이템 — 사장님이 스마트스토어 판매자센터에서 일괄등록 가이드 xls를 재다운로드해야 이 확인이 가능**(클로드가 원격으로 못 받음, 로그인 필요). 재다운로드 전까지는 레고 리스팅 상태를 "미확인"으로 유지하고 새로 완구 카테고리 SKU를 등록/변경할 때는 등록화면에서 직접 카테고리 트리를 확인할 것(guide xls 신뢰 보류). 다음 스마트스토어 스터디 때 xls 갱신 여부 재확인.
