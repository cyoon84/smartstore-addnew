**리뷰 원문을 블로그·SNS·자사몰·홍보물에 옮기면 저작권 문제가 된다.**
네이버가 리뷰 데이터 다운로드 시 직접 경고한다.

> 리뷰는 스마트스토어 노출 외 목적(자사몰 노출, 마케팅/홍보 등)으로 활용은
> **리뷰 작성자(저작권자) 동의 없이 불가능**합니다. 다운로드한 데이터 활용은 **판매자 책임** 하에 가능하며
> 관련하여 당사는 관여하지 않으며 책임을 부담하지 않습니다.

사장님: *"그대로 쓰면 소송 들어올수있어"*

## 쓸 수 있는 것 / 없는 것

| | |
|---|---|
| ❌ **리뷰 문장 직접 인용** | 짧아도, 아이디를 가려도, 오타를 살려도 안 된다 |
| ❌ **가까운 의역** | 특징적 표현("풍선껌 같은")을 그대로 옮기면 인용과 다를 바 없다 |
| ✅ **집계 수치** | 건수 · 기간 · 평균 평점 · 점수 분포 · 포토리뷰 비율 — 사실 데이터 |
| ✅ **경향 서술** | "달콤한 향이 먼저 언급된다" · "향이 약하다는 아쉬움도 한 건" 처럼 **우리 문장으로 요약** |
| ✅ **원문 보러 가기** | 상품 페이지 리뷰 탭으로 링크 유도 |

**타사 공식몰(P&G 등)의 고객 후기도 동일하다** — 작성자 저작물이라 인용 금지.
브랜드가 쓴 제품 소개문(마케팅 카피)은 출처 밝히고 짧게 인용 가능.

## 실무

- 리뷰 엑셀은 **경향 파악·집계용**으로만 연다. 문장을 산출물에 복사하지 않는다.
- 사장님 본인이 직접 느낀 것은 얼마든지 쓴다 — 리뷰에 같은 말이 있어도 **출처가 사장님이면 문제없다.**
- 낮은 점수도 숨기지 말되 **경향으로** 밝히고 대응(사용법 등)을 붙인다.
- 굳이 원문을 쓰고 싶으면 **작성자 동의**를 받는 경로뿐.

**Why:** 2026-08-20 다우니 퓨전 블로그 초안에 리뷰 6건을 원문 그대로 인용했다가
사장님이 네이버 다운로드 경고문을 들어 지적. 전량 삭제하고 집계·경향으로 재작성.
