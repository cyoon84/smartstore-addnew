## 🚨 2026-08-10 발견·정정 — "수취인별 주문" 잘못 cross off
COGS 반영할 때마다 "사야할 제품들"과 함께 "수취인별 주문" 쪽도 실수로 완료 처리함(§20-3 위반 — 수취인별 주문은 사장님이 포장하며 직접 체크). 최초 영향 대상으로 본 것: 박영훈(부모+셔츠), 신재민(부모+물병), 김다니엘(부모+오레오), 김수민(베르가못) — 6건. 전부 uncomplete했으나 **사용자 정정: 신재민·김다니엘은 실제로 포장 완료해 직접 체크한 것** → 그 둘(부모+자식 4건)은 다시 complete로 복구. **최종 미완료 = 박영훈(셔츠)·김수민(베르가못) 2건만 진짜 오류였음.** 앞으로 COGS 반영/재고소진 시 complete-tasks는 "사야할 제품들" 자식만 대상으로 하고 "수취인별 주문" 쪽은 절대 건들지 않는다.
