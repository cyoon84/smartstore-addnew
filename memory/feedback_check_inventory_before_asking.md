**사장님께 "이거 재고 있나요?" "누구 건가요?" "export 다시 주세요" 라고 묻기 전에 —
내가 열어볼 수 있는 출처를 전부 먼저 연다.**

확인 없이 묻는 건 규칙을 지킨 게 아니라 판단을 떠넘긴 것이다.

**확인 가능한 출처 (묻기 전에 전부)**

| 질문 | 먼저 열 곳 |
|---|---|
| 재고 있나 / 사야 하나 | `output/inventory/재고관리_*.xlsx` → 북키퍼 장부 `물건산거 (COGS)` 탭 |
| 누구 주문인가 / 몇 개인가 | **Todoist 프로젝트 `스마트스토어` `6gjhmh4gvvFQg75p`** (완료 항목까지) |
| 이미 산 건가 | 장부 COGS 탭 + 세션 시작 "정산 미반영 영수증" 목록 |
| 매출이 어느 배치인가 | `/Volumes/External/Downloads/스마트스토어_선택주문발주발송관리_*.xlsx` (암호 1111) |

**🚨 MCP 가 없다는 건 포기 사유가 아니다 — 브라우저로 직접 연다 (2026-11-13 신설).**
Todoist MCP 가 세션에서 빠져 있어도 Claude in Chrome 으로 `app.todoist.com` 탭에서 REST API 를 치면 된다.

```js
await fetch('/api/v1/tasks?project_id=6gjhmh4gvvFQg75p', {credentials:'include'}).then(r=>r.json())
// 완료 항목: GET /api/v1/tasks/completed/by_completion_date?since=…&until=…&project_id=…
// 수정 POST /api/v1/tasks/<id> · 완료 POST /api/v1/tasks/<id>/close · 되살리기 /reopen
```

> 2026-11-13 — 11/13 캐나다타이어 킨더 서프라이즈 3개가 **누구 건지 모르겠다**며 사장님께
> export 재발급을 요청했다. 사장님: *"아 todoist에 있잖아"* → *"왜 몰라?"*.
> 실제로 Todoist 에 백승미 2 · 강혜령 1 로 그대로 있었고, 브라우저로 여는 데 2분 걸렸다.
> 더 나쁜 건 **그 방법이 사장님이 주신 핸드오프 문서 21번째 줄에 적혀 있었고 내가 이미 읽었다**는 점이다.
> 한 경로(MCP)가 막히자 다른 경로를 찾는 대신 질문으로 넘어갔다.

**🔑 실패 패턴은 "몰랐다" 가 아니라 "한 경로만 보고 포기했다" 이다.**
아래 두 사고가 같은 모양이다 — 대상만 재고 엑셀 / Todoist 로 달랐다.
묻기 전에 스스로에게: **"지금 이걸 내가 열어볼 방법이 정말 하나도 없나?"**

**절차**
1. 재고관리 엑셀 최신본에서 **상품명 부분일치** 검색 (`~$` 로 시작하는 임시파일 제외).
2. 있으면 → **`사입단가(₩)` 로 COGS** 잡고, 시트 **`판매수량` +N** 차감,
   `메모` 에 `<날짜> <수취인> 주문(주문번호 …) 출고 — 재고 N 차감(현재고 M)` 기록.
3. 부분 재고면 `주문수량 − 재고 = 구매수량` 만 구매목록에.
4. 재고 시트에 없으면 → **북키퍼 장부 `물건산거 (COGS)` 탭을 상품명으로 grep** 한다.
   과거 구매가 있으면 그 수량과 이후 정산(`output/settlement/정산_*.md`) 사용분을 대조해 잔여를 센다.
5. 둘 다 없을 때만 구매 대상.
6. ⚠️ 이름이 비슷해도 **향·맛·용량·옵션이 다르면 다른 SKU** — 차감 금지 ([[feedback_product_name_verbatim]]).

**🚨 재고 시트에 행이 없다 ≠ 재고가 없다 (2026-11-03 신설).**
재고 시트는 **사람이 넣는 것**이라 빠질 수 있지만, 장부 COGS 탭은 **영수증 폴러가 자동으로 쌓는다.**
그래서 "시트에 없음 → 구매 필요" 로 결론내면 이미 집에 있는 물건을 또 사게 된다.

> 2026-11-03 11/3 배치 — `캐나다 코스트코 밴드에이드 (Band Aid) 대용량 220개입 ×1`(최영윤)을
> 재고 시트에 없다는 이유로 "구매 필요" 로 올렸다. 사장님: *"밴드에이드 재고 예전에 샀어"*.
> 장부 130행에 **2026-08-26 Costco Same-Day 에서 4개 구매**(프로모 −$27 안분 후 개당 $19.15 ·
> FX998.02 = ₩19,112)가 그대로 있었고, 8/31 우길조 1개만 나가 **3개가 남아 있었다.**
> 재고 시트에 그 행 자체가 등록 안 돼 있어서 절차 1·2 를 지켜도 안 잡혔다.
> → 97행으로 소급 등록 + 최영윤 1 차감(잔여 2).

**잔여 세는 법:** `장부 구매수량 − Σ(그 이후 정산 md 에서 그 품목이 COGS 로 나간 수량)`.
`grep -l "<상품명>" output/settlement/정산_*.md` 로 사용 배치를 한 번에 찾는다.

**Why:** 2026-08-31 최은숙 `캐나다 코스트코 대용량 세라비 모이스처라이징 크림 로션 453ml, 2개` —
재고 시트 23행에 **2026-07-29 Costco Downsview 사입분**(장은경 주문취소 → 재고전환, Costco Shop Card $25
적용해 실지출 $12.28, **사입단가 ₩13,299**)이 그대로 있었는데 확인 없이 *"구매 내역이 안 잡힙니다.
재고에 있나요, 새로 사야 하나요?"* 로 물었다. 사장님: *"사입 목록에 있잖아"* → ***"항상 물어본다"***.
