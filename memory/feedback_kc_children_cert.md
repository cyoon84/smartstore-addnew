**어린이제품 KC 인증 — 판매모델에 따라 다르다. 완구를 무조건 "인증대상 아님"으로 뭉뚱그리지 말 것.** (2026-07-09 KC 대행사 LooKC/아이씨티컴플라이언스 블로그로 정정.)

- **"어린이제품" 정의:** 만 13세 이하가 사용/위하여 사용되는 물품·부속품(초등학생까지). 사실상 어린이와 스치는 제품 전부 KC 인증 대상.
- **KC 인증 3종:** ①안전인증(공장심사 O — 물놀이/놀이기구/카시트/비비탄총) ②**안전확인**(공장심사 X — **완구**·유아섬유·스포츠보호·자전거·학용품·유모차 등) ③공급자적합성확인(유해도 낮음 — 가구·킥보드·장신구 + 개별기준 없는 것 전부). **완구(레고)는 "안전확인" 대상.**
- **일괄엑셀 한계:** 일괄등록 템플릿엔 KC 인증 필드가 없음(인증 칸은 '상품정보제공고시 인증허가사항' 하나뿐, KC ≠). → 완구/유아/블록/레고/인형/키즈/출산·육아 업로드 시 네이버가 인증정보 미입력이라 **자동 판매중지** → 네이버 상품편집에서 인증정보 채워야 판매중.

**How to apply (판매모델 구분):**
- **구매대행**(주문 후 개인 직구 대행): 구매자가 개인수입자 → KC 인증 의무 없음 → 네이버 인증 = **'인증대상 아님/구매대행'** 선택 가능.
- **직접 수입·사입 후 재고 판매(핀치마트 기본)**: **판매자가 KC 안전확인 인증 의무자** → '인증대상 아님'은 원칙상 부정확, 적발 시 **판매정지·과태료** 리스크. 소규모 직구셀러가 회색지대 운영은 하나 **리스크 인지하고 셀러가 최종 판단**.
- `build_bulk_excel.py` 가 완구/어린이 카테고리 감지 시 이 뉘앙스 경고 출력.

**Why:** 처음 "완구=인증대상 아님 선택"으로 뭉뚱그렸다가 블로그로 정정 — 완구는 KC(안전확인) 대상이 원칙이고, "인증대상 아님"은 구매대행 전제. 2026-07-08 레고 메시 43015(사입 재고)를 '인증대상 아님'으로 올린 건 구매대행 스탠스라 리스크 존재(사용자 인지). [[feedback_bulk_upload_excel]] · LEARNED §16

**추가 리스크(미확인, 모니터링만) — 2026-07-31 스터디:** 2024-06 시행 "KC 미인증 해외직구 원천차단"(어린이제품 34개·전기생활용품 34개·생활화학제품 12개, 유모차·완구 포함, 관세청 통관단계 차단)이 **개인 직구에만 적용되는지, 우리처럼 사입 후 국제소포(한미택배·우체국)로 개별 고객에게 발송하는 방식에도 적용되는지는 여러 소스(실무팩·언론)에서 명확히 확인 안 됨.** 우리 모델은 고객이 PCCC 를 제공하고 국제소포로 개별 통관되는 구조라, 통관 시스템 입장에선 개인 해외직구 소포와 형태가 유사할 수 있음. 확정되면 §16-2 의 "판매정지·과태료(사후 적발)" 리스크에 더해 **"소포 자체가 통관에서 막힐 수 있다"는 사전 차단 리스크**로 격상될 수 있음 — 완구/전기용품/생활화학제품 카테고리 신규 SKU 검토 시 참고, 근거 약해 반영은 보류.

**🔑 정정 — "원천차단"은 발표 3일 만에 철회, 실제로는 사전 전면차단이 아니라 사후 개별검사 방식 (2026-08-09 후속 스터디):** 위 2024-06 "80개 품목 통관 원천차단" 계획은 **2024-05-20 정부 발표 직후 소비자 반발로 사흘 만에 사실상 철회**됐다(서울신문 등 언론 확인). 이후 방식은 "국내 반입 후 개별 모델 유해성 검사 → 확인된 제품만 사후 차단"으로 바뀌었고, 2025년 정권교체 이후 전면 재추진 입법도 확인 안 됨. → **"소포 자체가 통관에서 막힐 수 있다"는 사전차단 리스크는 근거가 약해졌다(철회된 초기안 기준).** 실질 리스크는 여전히 §16-2 의 **KC 안전확인 인증의무(사후 적발 시 판매정지·과태료)** 쪽이지 통관 원천차단이 아니다. 다만 "사업자가 소유권 있는 재고를 개인 목록통관으로 발송"하는 방식이 관세법상 정식 수입신고 대상인지, 소액면세($150) 제도 개편 검토가 있는지는 여전히 미확인 — 완전히 안전하다고 단정하지 말고 §16-2 인증 의무 쪽을 계속 지킬 것.
