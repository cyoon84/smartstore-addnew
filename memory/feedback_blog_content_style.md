**🔑 블로그 본문은 HTML 아니라 텍스트다** — 상세페이지(§17 스타일드 HTML)와 다르다. 사장님이 네이버 블로그 에디터에서 직접 작성하므로 **붙여넣기용 텍스트 + "몇 번 이미지를 어디에 올릴지" 명시**가 산출물이다. (2026-07-26 HTML로 만들었다가 정정 — "html로 안했네 센서티브는.. 그냥 어떤 이미지 올릴건지 그것만 명시해줘")

화법은 **도브 센서티브 상세의 "🇺🇸 미국 제조 정품 확인" 섹션 방식**을 그대로 쓴다.

**5단 논증 구조:**
1. **고객이 실제로 하는 질문을 그대로 인용** — "도브, 이거 미국산 맞나요?" / "오리지널이랑 센서티브 뭐가 달라요?"
2. **직접 확인했다고 밝힘** — "두 제품 라벨을 글자 단위로 대조했습니다"
3. **라벨 원문·실물을 증거로** — 전성분 `PARFUM` 유무 · `for face, hands, and body` · 배치코드 각인 사진
4. **🔑 정직한 한계 고지** — "향 문제만 없다면 사용감 차이는 크지 않습니다" · "배치코드는 포장 안쪽이라 진열품에선 확인 불가"
5. **다음 콘텐츠 예고** — 시리즈로 묶어 재방문 유도

**Why:** 단정 → 증거 → 한계 인정 순서라야 신뢰가 쌓인다. 한계를 우리가 먼저 밝히면 기대 어긋남으로 인한 반품·컴플레인 소지도 준다. 셀러 글이 "광고"로 안 읽히게 하는 핵심이 3·4단계다.

**How to apply:** 산출물 = `output/blog/<slug>_초안.md` **한 파일**. 맨 위에 **📸 올릴 이미지 표**(번호·무엇·어디에·파일명/URL — 새로 찍어야 하는 것과 기존 재활용분을 구분 표기), 그 아래 제목 3안, 그 다음 `▼▼▼ 여기부터 본문 ▼▼▼` ~ `▲▲▲ 본문 끝 ▲▲▲` 사이에 붙여넣기용 텍스트(본문 안에는 `### 📸 이미지 N — 설명` + 캡션만 표시). 끝에 태그 10개(§10 통과어 재사용)·§9 일부러 안 쓴 것·게시후 체크리스트·다음 콘텐츠. **가격 숫자는 본문에서 뺀다** — 블로그는 오래 남고 가격은 바뀌니 링크로만 유도.

2026-07-26 도브 오리지널 vs 센서티브 글에서 확정 (사용자: "전에 도브 센서티브 미국산 확인하는법 보고 그런 스타일로 써" → 화법·포맷 둘 다).
