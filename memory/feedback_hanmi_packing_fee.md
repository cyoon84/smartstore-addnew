한미 배송비 공식(§7-1-0 `$8 + $4.5×(Paid−1kg) + 통관 $1`)은 **우리가 포장해 접수한 건** 기준이다.
물건을 한미로 바로 보내 **한미가 패킹하면 건당 $5 가 더 붙는다.**

```
실배송비($) = 8 + 4.5×(Paid−1) + 통관 1 + (한미패킹이면 5)
```

같은 배치에서도 **건별로 갈린다** — 자체 포장분과 한미 패킹분을 섞어 쓰면 각각 따로 계산한다.

**Why:** $5(≈₩4,900)가 주문 금액과 무관하게 정액으로 붙어 **소액·저마진 건을 적자로 뒤집는다.**
2026-09-01 배치에서 11건 패킹비 $55 가 순이익의 33%를 먹었고(₩164,876 → ₩110,690),
김미정이 +₩4,443 → −₩483 로 뒤집혔다. 이 $5 를 빼면 순이익이 실제보다 크게 나온다.

**How to apply:** 정산 표에 `패킹` 컬럼을 두고 어느 건이 한미 패킹인지 명시한다.
제품손익이 ₩25,000 아래인 건은 한미 패킹을 맡기기 전에 직접 포장을 검토한다.
