한미 배송비 공식(§7-1-0 `$8 + $4.5×(Paid−1kg) + 통관 $1`)은 **우리가 포장해 접수한 건** 기준이다.
물건을 한미로 바로 보내 **한미가 패킹하면 건당 $5 가 더 붙는다.**

```
실배송비($) = 8 + 4.5×(Paid−1) + 통관 1 + (한미패킹이면 5)
```

같은 배치에서도 **건별로 갈린다** — 자체 포장분과 한미 패킹분을 섞어 쓰면 각각 따로 계산한다.

**Why:** $5(≈₩4,900)가 정액으로 붙어 소액 건을 적자로 뒤집는다(2026-09-01 김미정 +₩4,443 → −₩483).
계산에서 빼먹으면 순이익이 과대 산출된다(₩164,876 → 실제 ₩110,690).

**🔑 단, "패킹비가 이익을 갉아먹었다"고 보지 말 것 — 비교 대상이 틀렸다.**
사장님이 한국에 계신 동안 **직접 포장은 선택지가 아니다.** 실제 비교는 `₩110,690` vs **`₩0`**
(주문을 못 받거나 연기)다. $5 는 비용 증가가 아니라 **매출을 성립시키는 조건**이다.
사장님: *"그래도 5$씩 붙어도 전체적으로 +면 괜찮다... 안그러면 주문 다 못받거나 미뤄야했는데."*

**How to apply:** 정산 표에 `패킹` 컬럼을 두고 한미 패킹 건을 명시한다. **판정은 건별 적자가 아니라
배치 전체 손익이 + 인가로 한다.** "직접 포장하자"는 권고는 사장님이 캐나다에 계셔서 실제로 가능할 때만.
적자 건이 나오면 패킹비 탓이 아니라 그 SKU 의 판매가·배송비를 재검토한다.
