**2026-11-03 첫 처리.** 네이버 스마트스토어 말고 **크로켓(Croket)** 이라는 별개 채널로도 판다.
거래 내역은 사장님이 **`<기간> 핀치마트셀러 거래 내역 리스트.xlsx`**(무암호, 네이버와 달리 비번 없음)
로 내려받아 준다.

## 네이버와 다른 점 (혼동 금지)

| | 네이버 | 크로켓 |
|---|---|---|
| 수수료 | 상품가 **6.6%** · 배송비 **3.63%** | 상품가 **13% + 그 부가세 10%** = 실질 14.3% · **배송비엔 0%** |
| 매출 기준 컬럼 | `정산예정금액`(BD) | `정산 예정 금액 (쿠폰, 광고 차감 전)` |
| 파일 암호 | `1111` | **없음** |
| 통관 | — | 주문마다 **개인통관고유부호** + `통관전용 주문번호` |

검산식: `상품가 − (상품가×13%×1.1) + 배송비 = 정산예정`
> 24,000 − 3,432(공급가 3,120 + 부가세 312) + 15,000 = **35,568** ✅

## 정산 파일

**`output/settlement/정산_크로켓_<YYYY-MM>.md`** 로 **채널 분리**한다.
네이버 출고일 정산(`정산_<출고일>.md`)에 섞지 않는다 — 수수료율이 달라 합치면 검산이 깨진다.
영수증은 `pending_receipts.py --mark "<key>" --batch "크로켓-<YYYY-MM>"` 으로 마크.
