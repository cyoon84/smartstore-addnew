🚨 **신규 SKU 후보는 라벨의 동물유래 원료를 §0-A 가격 판정보다 먼저 확인한다 — 통관·검역 리스크.**

영양제·식품 후보를 볼 때 §0-A(가격)·§0-D(수요)·§18-2(상세 금칙어)만 챙기고 **"이게 통관을 통과하나"** 는
안 보고 있었다. 후보 스크리닝에 **동물유래 원료 축**을 추가한다.

**확인 대상 = 라벨의 `non-medicinal ingredients`(부원료).**

| 성분 표기 | 유래 | 취급 |
|---|---|---|
| `gelatin [bovine]` · `beef gelatin` · `bovine collagen` · 우지(tallow) | **소·양 등 반추동물** | 🚨 **플래그 — 진행 전 사장님 확인** |
| `gelatin [porcine]` · `pork gelatin` | 돼지 | ⚠️ 확인 대상 |
| `fish gelatin` · `marine collagen` | 어류 | 상대적으로 낮음 |
| `HPMC` · `vegetarian capsule` | 식물성 | 문제 없음 |

- **연질캡슐(softgel) 영양제는 피막이 대부분 젤라틴이라 특히 주의.** bovine / porcine / fish / vegetarian
  중 무엇인지 라벨에서 반드시 확인 — 브랜드 공식몰 `Label Information`(Shopify `.js` 경로)에 그대로 나온다.
- **§0-A 가격 판정보다 먼저 한다.** 가격·수요가 좋아도 통관이 막히면 무의미하고, 산출물을 만든 뒤 접으면
  Codex 시각QA 왕복(회당 5~10분 × 2~3회)까지 통째로 버려진다.
- 이미 판매중인 연질캡슐 영양제(웨버 K2+D3·루테인·강황·오메가3류)는 **통관·판매 실적이 있으면 실증적으로
  통과한 것** — 신규 후보에만 이 게이트를 적용한다.
- 애매하면 자동으로 접지도 진행하지도 말고 **사장님께 플래그**(§21-1 과 같은 취급).

**Why:** 2026-08-21 웨버네추럴스 아스타잔틴 6mg 2×100정. 라벨 부원료가
`Softgel capsule (gelatin [bovine], purified water, glycerin), organic olive oil` 이었다.
나는 이걸 **정확히 읽어서 상세 주의사항에 "젤라틴 피막에 소 유래 성분이 들어 있습니다" 라고 적기까지 했는데**,
그걸 **소비자 고지**로만 처리하고 **통관 리스크**로는 한 번도 연결하지 않았다. 사장님이
*"성분에 gelatin [bovine] (소 유래) 있어서 괜히 통관에 문제 될수있음"* 으로 접음 — 산출물 4종·일괄엑셀·
`bulk-excel-verifier` PASS 가 전부 폐기.

**How to apply:** 라벨을 확보하면 성분마다 **(a)고객 고지 (b)§18-2 금칙어 (c)통관·검역** 세 축에
각각 걸리는지 따진다. 🔑 **라벨을 옮겨 적은 것은 검토한 게 아니다.**
