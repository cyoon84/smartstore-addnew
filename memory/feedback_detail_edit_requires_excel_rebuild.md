일괄**등록** 엑셀은 상세설명(Y칸)에 `detail.html` **전문을 복사해 넣는다.**
그래서 detail.html 만 고치고 엑셀을 다시 안 뽑으면 **엑셀 안에는 옛 상세가 그대로 남는다.**
사장님은 그 엑셀로 올리므로 **고친 카피가 반영되지 않은 채 등록된다.**

**🔑 사후 수정이 안 된다는 게 진짜 문제:** 일괄**수정** 양식에는 **상세설명 컬럼이 아예 없다**
([[feedback_naver_bulk_edit_excel]]). 등록 후엔 상품편집 화면에서 한 건씩 손으로 갈아끼우거나
**삭제 후 재등록**뿐이다.

**절대 규칙 — 셋은 한 묶음. 하나만 하고 끊지 말 것:**
```
detail.html 수정 → organize_output.py --apply → build_bulk_excel.py 재생성
```

- **카피 한 줄만 고쳐도 재생성한다.** "이미지·가격은 그대로니 엑셀은 안 건드려도 된다"가 오답 —
  상세 본문 자체가 엑셀 셀 안에 들어 있다.
- 사장님께 보낼 때 **엑셀과 상세를 같이** 보내고, 보내기 전 **엑셀 셀을 열어** 방금 고친 문구가
  들어있는지 문자열로 대조한다.

**Why:** 2026-08-09 0808 배치 — 카피를 전면 재작성(음역 제거·부정추천 어감·스펙 콜론)한 뒤 엑셀을
안 뽑았다. 사장님이 구버전 엑셀로 3종 등록(`13714109313~15`), 상세에 `알지오일`·`EWG 베리파이드`가
그대로 남아 있었다. 상세는 일괄수정으로 못 바꿔 **3종 삭제 후 4종 전부 재등록**.
