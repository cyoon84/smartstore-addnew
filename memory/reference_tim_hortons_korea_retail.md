**팀홀튼 국내 정식 유통 현황 (2026-07-24 사용자 확인):**

- **오리지널 블렌드**(907g 원두/그라운드)와 **일부 300g 그라운드 라인**이 **한국 코스트코 + 백화점 식품코너**에 정식 입점.
- → 이 SKU들은 직수입 각도가 죽음: 국내 오프라인 정가 + 무배송비 vs 우리 해외배송 ₩10,000+. §0-A 돌릴 필요도 없이 "가격으로 안 됨" 축. **취급 금지 리스트로 간주.**
- 네이버쇼핑도 이미 레드오션: "팀홀튼" 등록상품 2,767건, 상위 20이 전부 원두/분쇄(907g ₩26,000~36,000, 쿠팡·컬리·G마켓 포함).

**여전히 유효한 팀홀튼 축 (국내 미유통 추정 — 등록 전 §0-A로 개별 재확인):**
- K컵/캡슐 (큐리그 생태계가 한국에서 약해 정식 수입 가능성 낮음 — 현재 우리 K컵 80개입 판매 중, 실주문 발생)
- 프렌치바닐라 카푸치노 믹스 · 핫초코 (겨울 시즌) · 디카페인
- 캐나다 한정 시즌 맛 변형, 굿즈(머그·텀블러 — 단 국내 팀홀튼 매장 MD와 겹치는 디자인은 확인 필요)

**검색 데이터 맥락 (2026-07 데이터랩 실측):** "팀홀튼" 브랜드 단독 검색이 하위 결합어의 ~7배(캐나다 축 연중 1위). 하위는 커피(9.7) >> 원두(1.0) ≈ 텀블러(0.76) > 프렌치바닐라(0.42) > 핫초코(겨울 한정) > K컵(≈0). 성수기 9월~1월. K컵은 검색 0인데도 팔림 = "팀홀튼" 브랜드 검색→스토어 내 발견 구조. 2026-05 브랜드 검색 피크는 국내 유통 확대 버즈와 관련 가능성(가설).
