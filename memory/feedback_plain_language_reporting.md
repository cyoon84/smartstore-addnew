사장님께 보고할 때 **영어 단어를 한글로 음차해 쓰지 않는다.** 뜻이 통하는 한국어로 바꿔 쓴다.

**Why:** 2026-09-25 정산 보고에서 재고 사입 묶음을 계속 **"로트"** 라고 썼다. 사장님이
*"로트는 뭐야?"* → *"로트라는 단어가 일상생활에서도 쓰냐고"* → **"알아듣게 해"**.
내가 이걸 "업계 용어"라고 변명하자 → **"이건 업계용어도 아니고 그냥 영어 음차한거같은데"**.
정확한 지적이다. `lot` 을 한글로 옮겨 적었을 뿐 한국어로 뜻이 전달되는 말이 아니다.

**이미 있던 규칙을 보고문에만 안 지켰다.** LEARNED_RULES §5-1(제품 타입 외래어는 음역 대신
한국어 통용어 — raw honey → ❌`로우 허니` / ✅`생꿀`)과 **완전히 같은 원칙**인데,
상품 카피에만 적용하고 채팅 보고에는 안 썼다. 적용 범위를 보고문까지 넓힌다.

**How to apply:**
| ❌ 쓰지 말 것 | ✅ 이렇게 |
|---|---|
| 로트 | **9/22 사입분** · **9/4 실사분** · "언제 산 것" |
| landed 원가 | **실제 들어간 값(배달비·세금 포함)** |
| 안분 · 배분비율 | **수수료를 품목별로 나눠 얹은 값** |
| ΣBD · BD | **네이버 정산예정금액** |
| dedup | **중복 제거** |
| FX | **환율** |
| PA | **가격 보정 환불** |
| 세액역산 | **세금 $3.89 를 13% 로 나눠 거꾸로 계산** |

- **적용 범위 = 사장님께 보내는 말뿐이다** (2026-09-25 사장님: *"너 혼자서 중얼거릴땐 로트든 뭐든 상관없지만
  나한테 보고할때는 그렇게 쓰도록"*). 내 사고 과정·중간 계산·스크립트·컬럼명·파일 안 메모·Codex 프롬프트 등
  **사장님이 안 읽는 곳에서는 원어를 그대로 써도 된다.** 용어를 없애는 게 목적이 아니라 **보고가 바로 읽히는 게 목적**이다.
- 채팅 보고문·Slack 메시지·노션 기록처럼 **사장님 눈에 닿는 글에는 반드시 풀어쓴다.**
- 꼭 원어를 써야 하면 처음 한 번 괄호로 풀이를 붙이고 이후엔 한국어로 통일한다.
- 판별법: **그 단어를 사장님이 되물어야 한다면 쓰지 않는다.**
