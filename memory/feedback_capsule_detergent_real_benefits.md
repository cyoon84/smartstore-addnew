캡슐(팟)형 세탁세제의 **진짜 소구점 2개** — 사용자 장모님 실사용 피드백 (2026-07-24 타이드 포드 104개입 개편):

1. **"밤에 어두울 때 세탁할 때 계량 신경 안 써도 좋다"** — 불 안 켜고, 눈금 볼 필요 없이 캡슐 하나 집어 넣으면 끝. → 타겟 "퇴근 후 늦은 밤 세탁하는 분"
2. **"무거운 세제 들 필요 없어서 손목에도 좋다"** — 큰 통을 매번 기울일 필요 없음. → 타겟 **"손목 약한 분·어르신"** (시니어·부모님 선물 각도 확장)

**Why:** 캡슐세제 일반 카피는 "간편하다"에서 멈춘다. 실사용자는 **구체적 순간**(야간·불 안 켬 / 통 기울이기)으로 말하고, 그게 훨씬 잘 꽂힌다. LEARNED §17-1 "기능→결과·시간·숫자로 번역"의 교과서 사례.

**🔑 클로드는 이걸 스스로 못 잡는다 → 매번 먼저 물어라 (2026-07-24 사용자 지적 "니가 캐치를 못했겠지"):** 클로드가 보는 건 라벨·브랜드 공식카피·검색량뿐이고, 그건 전부 **제조사가 자랑하고 싶은 것**(4in1·멀티챔버·냉수용해필름)이다. 실사용 소구점은 라벨에도 없고 검색량에도 없어서 **추론으로 도달 불가**(몸이 없으니 세제통을 들어본 적도, 어두운 세탁실에서 눈금을 찾아본 적도 없다).
→ **상세 개편·신규 등록 때 산출물 내기 전에 "이거 직접 써본 사람 있어? 쓰면서 좋았던 점/불편한 점?"을 먼저 묻는다.** 사장님·가족·지인 실사용 한 줄이 브랜드 카피 열 줄을 이긴다. 답이 없으면 그때 스펙 기반으로 진행.

**🔑 검색 데이터로 검증됨 (같은 날 태그 입력화면):** 캡슐세제 태그 최강이 **`간편세제`(1,217,264)·`간편세탁`(318,449)** — 실사용 피드백의 "계량 신경 안 써도 좋다"와 **정확히 같은 축**이었다. 내가 스펙에서 뽑아 밀었던 `대용량팩`·`대용량세제`·`4인가족`은 전부 미채택. → **실사용 소구점은 카피만 좋아지는 게 아니라 태그·상품명 축까지 바꾼다.** `부모님선물`(6,711) 채택도 "무거운 통 안 들어서 손목에 좋다"의 시니어 각도와 연결.

**How to apply:**
- 캡슐/팟형 세제 SKU(타이드 파워포드 45개입·프리앤젠틀 152개입 등) 상세에 **같은 앵글 재사용**
- 무게·계량 부담이 있는 다른 카테고리(대용량 액체세제 vs 소분형, 분말 vs 캡슐)에도 응용
- ⚠️ **후기 블록으로 위장 금지** — 지인 피드백이므로 "고객 후기"로 넣지 않고 `이런 점이 좋아요`·`이런 분들께 추천` 편익 서술로만 (§9 데이터 진실성). 실제 스토어 리뷰가 쌓이면 그때 정량 증거로 (§17-1).

## 같은 패턴 2번째 사례 — 이머전씨 "커피 대신" (2026-07-24)

사용자: **"커피 대신 찾는 사람도 많아"** (이머전씨 발포비타민C 90포). 라벨엔 `Immune Support`·`Energy Production`만 있고 **"커피 대체"는 어디에도 없다** — 또 추론으로 도달 불가한 앵글. 그런데 제품 사실(**무카페인**)과 정확히 붙고, 태그 `무카페인`(656,238)까지 연결된다.
- 반영: 훅("오후엔 커피만 또 한 잔") · 이런점이좋아요 1번 · 추천 1번 · 태그 `무카페인` 최우선
- 뒷받침: [직장인 발포비타민 설문](https://www.everynews.co.kr/news/articleView.html?idxno=25741) — 발포 선호 이유 "음료처럼 느껴진다" 30.5%·"탄산의 재미" 30.5%, **오후 2~4시** 카페인 섭취. 단 기사형 콘텐츠(베로카 언급)라 **수치는 상세에 인용하지 않고 앵글만** 차용.
- ⚠️ **효능 프레임 전이 주의:** "커피 대신"에서 "피로 회복"으로 넘어가면 §18-2 효능 표현 위반. **시간대 시나리오 + 무카페인(사실)까지만.**

**후속 (같은 날) — 실사용 인물이 구체화되면 카피가 또 한 단계 정확해진다:** 사용자 추가 정보 **"커피 안 드시는 장모님도 일 갈 때 꼭 챙겨 나가시는 제품"**. → ①**대체 수요는 두 층이다 — "아예 안 마시는 층" + "줄이고 싶은 층"** (사용자 정정: "커피를 줄이고 싶은 사람도 할 수 있지!"). 장모님 케이스는 *완전 대체 층이 실제로 존재한다는 증거가 추가된 것*이고, **줄이려는 층이 모수는 더 크다**(커피 인구 ≫ 비커피 인구) → 어느 한쪽으로 좁히지 말고 `"안 마시는 분도, 줄이려는 분도"`로 양쪽 커버 ②막연한 "휴대 편리"가 아니라 **출근 가방에 매일 챙기는 습관품** → "출근할 때 가방에 몇 포만"으로 구체화. **처음 답보다 두 번째·세 번째 디테일이 더 쓸모 있으니, 실사용 얘기가 나오면 "누가·언제·어디서"까지 캐물을 것.**

> 🔑 **장모님 = 우리 스토어의 실사용 레퍼런스 인물** (2026-07-24 기준 2개 SKU에서 앵글 제공: 타이드 캡슐세제·이머전씨). 생활용품·건강식품 시니어 관점이 강하니, 해당 카테고리 개편 시 **"장모님이 써보신 거 있어요?"**를 먼저 물어볼 가치.

→ **일반화: 제품 사실(무카페인·경량·소분 등)과 붙는 "대체 수요" 앵글은 사용자에게 물어야 나온다.** 카테고리 상식(비타민=영양제)만 보면 놓친다.
