네이버 상품상세는 특정 단어를 **등록 자체로 막는다**(하드블록). 에러: `"상품상세 항목에 등록불가인 단어(<단어>)가 포함되어 있습니다. 해당 단어는 '<단어>:기타' 사유로 사용이 불가합니다."` 상품명 SEO 권고(§5)와 달리 저장이 안 되므로 **작성 단계에서 걸러야** 재작업이 없다.

**Why:** 2026-07-24 커클랜드 데일리 프로바이오틱 상세에서 **`림프종`** 거부. 원인은 캐나다 NPN 라벨 문구(`Helps to improve abdominal pain related to IBS`, 면역저하 금기에 병명 나열)를 **직역해서 쓰고 있던 것**. 해외 인정문구는 그 나라 기준이라 한국 상세에 그대로 쓰면 금칙어 + 식약처 부당광고(의약품 오인) 리스크가 겹친다.

**How to apply:**
- **거부 확인:** `림프종`. **선제 제거 대상(같은 계열):** 질병명(에이즈·암·장염·궤양·당뇨·고혈압·IBS/과민성) · 의약품명(코르티코스테로이드·스테로이드·항생제·처방) · 효능표현(치료·완치·개선·예방·억제·효능·진단·증상) · 과장어(보장·최고·1위·완벽·100%).
- **대체 방식:** 병명 → "면역 기능이 저하된 상태" 로 일반화 / "항생제 복용 시" → "다른 약과 함께라면" / "이상 증상" → "몸 상태가 좋지 않은 경우" / "유통기한까지 보장"(guaranteed to expiry) → "유통기한까지 유지".
- **안전 고지는 살린다.** 라벨 경고문(섭취 전 상담·3일 이상 지속 시 중단·면역저하자 금지·밀봉 손상 시 금지)은 신뢰에 좋으니 유지하고 **그 안의 병명·약품명만** 일반화. 경고 문맥이어도 필터엔 똑같이 걸려 예외 없음.
- **효능 대신 스펙으로 판다.** 커클랜드는 IBS 클레임을 빼고 균주별 CFU·지연방출 캡슐·프리바이오틱 함량(이눌린 150mg)·90캡슐 3개월분으로 재구성.
- **업로드 전 자가검사:** 상세 HTML 태그 제거 → 위 단어 목록 전수 grep → 0건 확인.

§10의 "증상/질병명 태그 금지, 효능어로 우회"와 같은 맥락이지만 **태그뿐 아니라 상세 본문에도 적용**된다는 게 이 규칙의 요지. 상세 규칙 = LEARNED_RULES §18-2. 관련: [[feedback_naver_field_limits]] · [[feedback_detail_styled_deco_template]] · [[feedback_senior_copywriting_mindset]]
