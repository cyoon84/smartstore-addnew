## 🚨 최우선 — 다음 한미 송장 생성 시 절대 규칙

사용자가 다음 발주목록 엑셀을 주고 한미 송장을 만들어 달라고 하면, 엑셀을 그대로 전량 변환하지 말고
아래 다섯 가지를 **송장 생성 전 필터·수량 QA의 최우선 규칙**으로 적용한다.

1. **윤기순은 이번 송장에서 제외(ignore).**
   - 발주목록 엑셀에 윤기순 주문이 포함돼 있어도 이번 출고분이 아니다.
   - 윤기순 네스카페 Hazelnut 5 + French Vanilla 5는 **2026-08-04 출고분**이다.
   - 이번 한미 송장에 윤기순 entry를 만들지 않는다.
2. **윤덕훈은 총수량 18개만 송장에 넣는다.**
   - 36개 전체를 넣으면 안 된다.
   - 이번분: Blonde Espresso 2 + Vanilla Flavored 4 + Espresso 8 + French Roast 4 = **총 18개**.
   - 나머지 18개는 2026-08-04 출고분이다.
3. **조은비 파인솔은 송장에 반드시 2 entries를 만든다.**
   - 동일 수취인 조은비로 별도 박스/entry 2개 생성.
   - 1번째 entry: 파인솔 **8개**.
   - 2번째 entry: 파인솔 **2개**.
   - 한 entry에 10개를 합치거나 5+5로 나누지 않는다.
4. **송영진은 이번 송장에서 제외(ignore).**
   - 최신 7/31 export에 포함돼 있어도 사용자 요청으로 **2026-08-04(화) 출고분**으로 이월했다.
   - 이번 한미 송장에 송영진 entry를 만들지 않는다.
   - 화요일분 상품: `룰루레몬 백투라이프 스포츠보틀 18oz 빨대뚜껑 진공보냉 물병 블리스풀핑크, 1개 × 1`.
5. **배성민은 이번 송장에서 제외(ignore).**
   - 최신 7/31 export에 포함돼 있지만 오늘 출고가 불가능해 **2026-08-04(화) 출고분**으로 이월했다.
   - 이번 한미 송장에 배성민 entry를 만들지 않는다.
   - 화요일분 상품: `네스프레소 버츄오 캡슐 커피 화이트 초콜렛 스트로베리 발렌타인데이, 10개입, 1개 × 3`.
