→ 294행 삭제, 171행 메모에 이력 기록. 9월 COGS $44.74 과대계상 해소.

🔑 **구조적 원인 — 환불로 순액 정정한 행은 원본 금액을 기억하지 못한다.** `find_duplicate()` 가
`날짜 + total` 만 보는데, 171행을 $44.74 → $26.73 으로 고쳐둔 탓에 폴러가 원본을 재수집했을 때
날짜만 같고 금액이 달라 중복 판정을 빠져나갔다(merchant 는 애초에 판정 대상이 아니다 — 처음에 내가
"merchant 문자열이 달라서" 라고 보고한 건 오진).
→ `add_expense.py` 에 메모의 **`[dup-key:<날짜>|<금액>]`** 마커 판정을 추가했다. **앞으로 환불·부분취소로
행을 순액으로 고칠 때는 그 메모에 원래 총액을 `[dup-key:...]` 로 남긴다.** 171행에 적용·재수집 스킵 검증 완료.
